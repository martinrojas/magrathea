# Magrathea

Martin Rojas's personal OMP plugin marketplace. Catalog: `.omp-plugin/marketplace.json`.

```text
/marketplace add <owner>/<this-repo>
/marketplace install <plugin>@magrathea
```

| Plugin | Description |
|---|---|
| [omp-superpowers](plugins/omp-superpowers/) | Superpowers-derived brainstorm → plan → execute → finish workflow with model-role-routed agents |
| [playon-standard](plugins/playon-standard/) | PlayOn Source-of-Truth Standard: adopt, sync docs, decisions, domain rules, upgrade |
